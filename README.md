# SCDev | `scdev`

**ID:** `sixslime.scdev`

> Chat-based frontend and utility for SlimeCore.

## Description

SCDev is a chat-based frontend for [SlimeCore](https://github.com/sixslimemc/slimecore), designed to be simple and accessible for all users. In addition to providing basic frontend features, it includes a handful of utilities that may be useful for development and general management of SlimeCore-loaded datapacks.
